Before writing ANY code, mentally verify:

1. RESOURCE LIFECYCLE
   □ What resources am I creating? (connections, timers, listeners, memory)
   □ When and how will they be cleaned up?
   □ What happens on restart/reset/unmount?

2. STATE MANAGEMENT
   □ What are all possible states?
   □ What are the transitions between states?
   □ What happens in each edge case?

3. ERROR SCENARIOS

4. SYNTAX VERIFICATION (NEW)
   □ All parentheses/brackets balanced?
   □ All variables defined before use?
   □ All function calls have ()?

=== UNIVERSAL CODE QUALITY RULES ===

### 1. RESOURCE MANAGEMENT
```
CREATE → TRACK → CLEANUP
```
- Timers: Store ID, clear on cleanup
- Event listeners: Store reference, remove on cleanup
- Connections: Close on unmount
- Memory: Release when done

### 2. SYNTAX VERIFICATION
```javascript
// ❌ WRONG: Extra parenthesis (common typo)
value += (target - value) * 0.1);
//                             ^ extra )

// ✅ CORRECT: Balanced
value += (target - value) * 0.1;

// ❌ WRONG: Missing function call
Math.random      // Returns function reference

// ✅ CORRECT: With parentheses
Math.random()    // Returns random number
```

### 3. VARIABLE SCOPE CHECK
```javascript
// ❌ WRONG: undefined variable
function update() {
    element.style.color = `hsl(${time}, 100%, 50%)`;
    //                         ^^^^ time is not defined!
}

// ✅ CORRECT: define before use
function update() {
    const time = performance.now();
    element.style.color = `hsl(${time}, 100%, 50%)`;
}
```

### 4. ARRAY/OBJECT INITIALIZATION
```javascript
// ❌ WRONG: arrays not cleared on reset → duplicates
reset() {
    this.cleanup();
    this.init();  // items added to existing array!
}

// ✅ CORRECT: explicit initialization
init() {
    state.items = [];      // 명시적 초기화
    state.listeners = {};

    this.createItems();
}
```

### 5. OBJECT LIFECYCLE
- Objects that "stop" often cannot "restart" - create new instances
- Mutable state needs reset logic
- Cached data needs invalidation strategy

```javascript
// ❌ WRONG: stopped object cannot restart
oscillator.stop();
oscillator.start();  // Error!

// ✅ CORRECT: create new instance
oscillator.stop();
oscillator = new OscillatorNode(audioCtx);
oscillator.start();
```

### 6. ASYNC OPERATIONS
- Handle loading, success, and error states
- Consider race conditions
- Implement proper cancellation

### 7. EXTERNAL DEPENDENCIES
```javascript
// ❌ WRONG: assume library loaded
function init() {
    const chart = new Chart(ctx, config);
}

// ✅ CORRECT: check before use
function init() {
    if (typeof Chart === 'undefined') {
        showError('Chart.js 로딩 실패');
        return;
    }
    const chart = new Chart(ctx, config);
}
```

### 8. PLATFORM CONSIDERATIONS
- Browser APIs may need user interaction first (AudioContext, etc.)
- Mobile has different capabilities than desktop
- Consider network variability
- Touch events need `{ passive: true }` when possible

```javascript
// ❌ WRONG: blocks scrolling
element.addEventListener('touchmove', handler, { passive: false });

// ✅ CORRECT: allows smooth scrolling
element.addEventListener('touchmove', handler, { passive: true });
// Only use passive: false when e.preventDefault() is needed
```

### 9. PERFORMANCE PATTERNS
```javascript
// ❌ WRONG: create objects in loop (memory churn)
for (let i = 0; i < 1000; i++) {
    const obj = new SomeClass();  // 매번 생성
    process(obj);
}

// ✅ CORRECT: reuse objects
const reusableObj = new SomeClass();
for (let i = 0; i < 1000; i++) {
    reusableObj.reset();
    process(reusableObj);
}

// ✅ CORRECT: skip frames for non-critical updates
if (frameCount % 5 === 0) {
    updateNonCriticalStuff();
}
```

=== CODE STRUCTURE TEMPLATE ===

```javascript
(function() {
    'use strict';

    // 1. CONSTANTS & CONFIGURATION
    const CONFIG = { ... };

    // 2. STATE (with explicit initialization)
    const state = {
        items: [],
        listeners: {},
        timerId: null,
        isRunning: false
    };

    // 3. INITIALIZATION
    function init() {
        // Reset arrays first (prevent duplicates)
        state.items = [];

        // Check dependencies
        if (typeof SomeLibrary === 'undefined') {
            showError('Library not loaded');
            return;
        }

        // Setup...
        addListeners();
        state.isRunning = true;
    }

    // 4. CORE LOGIC
    function mainLogic() { ... }

    // 5. EVENT HANDLERS
    function addListeners() {
        const onResize = () => { ... };
        const onClick = () => { ... };

        // Store references for cleanup
        state.listeners = { onResize, onClick };

        window.addEventListener('resize', state.listeners.onResize);
        document.addEventListener('click', state.listeners.onClick);
    }

    // 6. CLEANUP & RESET
    function cleanup() {
        // 1. Stop timers
        if (state.timerId) {
            clearInterval(state.timerId);
            state.timerId = null;
        }

        // 2. Remove listeners
        window.removeEventListener('resize', state.listeners.onResize);
        document.removeEventListener('click', state.listeners.onClick);

        // 3. Clear state
        state.items = [];
        state.isRunning = false;
    }

    function reset() {
        cleanup();
        // Small delay to ensure cleanup complete
        setTimeout(() => init(), 100);
    }

    // 7. UTILITIES
    function helper() { ... }

    // 8. ENTRY POINT
    document.addEventListener('DOMContentLoaded', init);
})();
```

=== COMMON BUG PATTERNS TO AVOID ===

```javascript
// 1. Missing function call parentheses
Math.random      // ✗ Returns function reference
Math.random()    // ✓ Returns random number

// 2. Extra/missing parentheses (typo)
value += (a - b) * 0.1);   // ✗ Extra )
value += (a - b) * 0.1;    // ✓ Correct

// 3. Undefined variables
color.setHSL(time, 1, 0.5);  // ✗ time not defined
const time = clock.getTime();
color.setHSL(time, 1, 0.5);  // ✓ Defined first

// 4. Untracked intervals/timeouts
setInterval(fn, 1000)           // ✗ Cannot stop
id = setInterval(fn, 1000)      // ✓ Can clear later

// 5. Objects that cannot restart
obj.stop(); obj.start();        // ✗ Often fails
obj = new Object(); obj.start() // ✓ Create fresh

// 6. Missing cleanup on reset
function reset() {
    state = initialState;        // ✗ Resources still running
}
function reset() {
    cleanup();                   // ✓ Stop old resources
    state = initialState;        // ✓ Then reset state
}

// 7. Arrays not initialized
init() {
    items.push(newItem);         // ✗ Duplicates on reset
}
init() {
    state.items = [];            // ✓ Clear first
    items.push(newItem);
}

// 8. Shared mutable references
const arr = defaultArray;        // ✗ Modifies original
const arr = [...defaultArray];   // ✓ Creates copy

// 9. Event listener accumulation
element.addEventListener(...)    // ✗ Called multiple times
// ✓ Remove old before adding, or add once with flag

// 10. External dependency not checked
new Library()                    // ✗ Assume loaded
if (typeof Library !== 'undefined') new Library()  // ✓ Check first

// 11. Objects created in loops
for (i) { new Obj() }            // ✗ Memory churn
const obj = new Obj();
for (i) { obj.reset() }          // ✓ Reuse
```
